# 5. DOWNLOAD PRETRAINED MODEL WEIGHTS
# ============================================================================
#
# The model weights are hosted on HuggingFace. There are two approaches:
#
# ─── Option A: Automatic download (recommended) ─────────────────────────────
#
# The pipeline will auto-download weights on first run.
# Just run generate.py and it will download ~10GB of weights to
# your HuggingFace cache (~/.cache/huggingface/).
#
# No action needed — skip to Section 6!

# ─── Option B: Manual pre-download ──────────────────────────────────────────
#
# If you want to pre-download before running, or need offline access:

# Install the HuggingFace CLI:
pip install huggingface_hub[cli]

# Login (optional, needed only for gated models):
huggingface-cli login
#   Enter your HuggingFace access token from https://huggingface.co/settings/tokens

# Download Hunyuan3D-2 weights (v2.0 — ~10GB):
huggingface-cli download tencent/Hunyuan3D-2 --local-dir ./pretrained/Hunyuan3D-2

# OR download Hunyuan3D-2.1 weights (v2.1):
huggingface-cli download tencent/Hunyuan3D-2.1 --local-dir ./pretrained/Hunyuan3D-2.1

# Key weight files that will be downloaded:
#   pretrained/Hunyuan3D-2/
#   ├── hunyuan3d-dit-v2-0/           # DiT (diffusion transformer) weights
#   │   ├── model.safetensors         # ~4GB
#   │   └── config.yaml
#   ├── hunyuan3d-vae-v2-0-withencoder/  # ShapeVAE weights
#   │   ├── model.safetensors         # ~2GB
#   │   └── config.yaml
#   └── ...

# ─── Option C: Download specific subfolders only ─────────────────────────────
#
# To save disk space, download only the shape generation weights
# (skip texture/paint weights):

python -c "
from huggingface_hub import snapshot_download
snapshot_download(
    repo_id='tencent/Hunyuan3D-2',
    local_dir='./pretrained/Hunyuan3D-2',
    allow_patterns=[
        'hunyuan3d-dit-v2-0/*',
        'hunyuan3d-vae-v2-0-withencoder/*',
    ],
    ignore_patterns=[
        'hunyuan3d-paint-*',
        'hunyuan3d-delight-*',
    ],
)
print('Shape generation weights downloaded successfully!')
"

#

# BALANCED → Production use, good quality/speed tradeoff
# ULTRA    → Final assets, maximum geometric detail, presentation quality
#

# ============================================================================
# 10. POST-PROCESSING OPTIONS
# ============================================================================
#
# The 8-step post-processing pipeline:
#
#   1. REPAIR        Remove degenerate faces, duplicate faces, merge close
#                    vertices, fix non-manifold edges
#
#   2. FLOATER       Remove small disconnected components (noise blobs)
#     REMOVAL        that appear as floating geometry
#
#   3. NORMAL        Reorient all faces for consistent outward-facing
#     FIXING         normals, recompute vertex normals
#
#   4. HOLE          Fill small holes in the surface (max edges threshold
#     FILLING        controls which holes get filled)
#
#   5. SMOOTHING     Taubin: λ|μ filter (volume-preserving, general use)
#                    HC: Humphrey's Classes (better at preserving edges)
#
#   6. SUBDIVISION   Loop subdivision for smoother surfaces (BALANCED/ULTRA)
#                    Approximately 4× faces per iteration
#
#   7. DECIMATION    Quadric Edge Collapse to reduce face count to target
#                    Preserves boundaries, normals, and topology
#
#   8. VALIDATION    Check watertightness, manifoldness, degenerate faces
#                    Output a quality report
#
# ── Disable individual steps: ──
python generate.py --image in.png --no-smooth --output out.glb
python generate.py --image in.png --no-repair --output out.glb
python generate.py --image in.png --no-decimate --output out.glb
python generate.py --image in.png --no-postprocess --output out.glb

# 11. EXPORT FORMATS

# ┌────────┬───────────────────────────────────────────────────────────────────┐
# │ Format │ Description                                                      │
# ├────────┼───────────────────────────────────────────────────────────────────┤
# │ GLB    │ Binary GL Transmission Format. Single file, compact.             │
# │        │ Best for: web viewers, game engines, Three.js, Babylon.js        │
# │        │ Includes: vertex positions, normals, face indices                │
# ├────────┼───────────────────────────────────────────────────────────────────┤
# │ OBJ    │ Wavefront OBJ. ASCII text format, most widely supported.         │
# │        │ Best for: Blender, Maya, 3ds Max, ZBrush, any DCC tool          │
# │        │ Includes: vertices (v), normals (vn), faces (f)                 │
# ├────────┼───────────────────────────────────────────────────────────────────┤
# │ STL    │ Stereolithography. Binary format. Industry standard.             │
# │        │ Best for: 3D printing (Cura, PrusaSlicer), CAD/CAM              │
# │        │ Includes: triangles with face normals                           │
# ├────────┼───────────────────────────────────────────────────────────────────┤
# │ PLY    │ Stanford Polygon File. Binary or ASCII.                          │
# │        │ Best for: research, point cloud tools, MeshLab                  │
# │        │ Includes: vertices, normals, faces, custom properties           │
# └────────┴───────────────────────────────────────────────────────────────────┘
#

# 13. TROUBLESHOOTING
# ============================================================================

# ─── Problem: "CUDA out of memory" ──────────────────────────────────────────

# ─── Problem: "Marching Cubes produced empty mesh" ──────────────────────────
# This means the SDF field has no zero-crossing (no surface detected).
# Possible causes:
#   - Bad input image (too dark, blurry, no clear object)
#   - Model weights not loaded correctly
# Solutions:
#   - Try a clearer input image with a single object
#   - Try a different seed: --seed 123
#   - Increase steps: --steps 100

pip install safetensors huggingface_hub --upgrade

huggingface-cli download tencent/Hunyuan3D-2 --force-download
